# Cutie Smart AI

An AI-powered desktop assistant built with Python, designed for smart interactions and local execution on Windows.

## Features

- **Smart Assistant Core:** Powered by `main.py` and `jarvis.py` modules.
- **Interactive / Visual Interface:** Built with `pygame-ce` support.
- **Windows Executable Support:** Can be packaged as a standalone `.exe` using PyInstaller.
